# 木綿街道、静かな一日。

町家の写真、老舗の手仕事、地元の料理を眺めながら、松江発の日帰り旅を計画するデジタルパンフレットです。

公開先：[木綿街道、静かな一日。](https://anemia111.github.io/momen-kaido-guide/)

## 写真から旅を選ぶ

- 深緑とアイボリー、大きな町家の写真、ゆったりした余白を使ったデザイン。
- 814・棉の花・喜多縁の料理と店内、老舗の商品・店構え・手仕事、本石橋邸の庭と座敷、ゆらりの露天風呂。
- 写真の切り替えと拡大表示。店名・キーワード検索、種類による絞り込み。
- 風風ラーメン平田店の公式メニュー全5ページ（2025年7月掲載）。
- 公式散策マップの表裏、両駅の公式時刻表、平日／土日祝の旅程、電話・予約・地図へのボタン。
- 各写真の掲載元リンク。814の夕食紹介写真はその旨を記載。加藤醤油店は確認済み写真がないため案内カードを表示。

## 旅を計画・現地で使う

- 上部で「旅を計画」「現地で使う」を切り替えます。計画モードの日付入力は「出発前に確認」、現地モードでは上部にあります。選んだ旅行日とモードは端末内に保存されます。
- 日付指定中は平日／土日祝ダイヤを自動選択します。手動で選ぶ場合は日付をクリアしてください。日付未指定の初期区分と現地の現在時刻は日本時間です。
- 現地モードは次・その次の予定と帰りの電車、地図・運行情報・店舗営業情報・電話を先に表示します。旅行日が今日以外なら予定日を表示し、現在時刻による案内は行いません。
- 街道MAP・6km散歩・スポットMAPをタブで切り替えます。矢印キー、Home、Endでも操作できます。LeafletはスポットMAPを開くまで読み込みません。
- 飲食店も検索対象です。検索結果から元の飲食店カードへ移動できます。

祝日判定は[内閣府の祝日一覧・現行法](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)を根拠に、2022〜2099年の現行ルール、振替休日・国民の休日を実装しています。2026・2027年の春分・秋分は公式掲載日、2028年以降は推計です。将来の法改正や特例休日は更新が必要です。定休日は既存データの出典から構造化し、祝日翌日の休館も注意表示します。営業状況を断定するシステムではありません。

`src/data/editorial.ts` の休館案内は `start`・`end`・任意の `displayFrom` を持ちます。旅行日指定時は該当する案内だけ、未指定時は表示開始日以降かつ終了前の案内だけ表示します。`displayFrom` がなければ開始30日前から表示します。

## オフライン

本番ビルドでService Workerと約7.5MBの事前キャッシュ一覧を生成します。オンラインで初回保存が完了した後、アプリ、旅程・施設データ、写真、公式地図画像、散歩画像、両駅の時刻表画像が利用できます。外部サイト、外部地図、PDF原本、OpenStreetMapタイルは保存対象外です。オフライン時には控えめな通知を表示します。

アセットの内容からキャッシュの版を作成し、すべての保存が成功してから新しい版を有効にします。更新中は開いている旧版を維持し、次回起動時に更新します。容量制限や端末側のデータ削除により保存が失われる場合はオンラインで再度開いてください。

## 開発と確認

`npm ci` → `npm run lint` → `npm run format:check` → `npm run build` → `npm test`

375・390・393・430pxのWebKit、768・1440pxのChromiumで、写真操作、検索、旅程、時刻表、地図、共有、タップ領域、アクセシビリティを確認します。mainへの更新はGitHub Actionsで検証し、GitHub Pagesに公開します。

写真の掲載元は `public/brochure-photos/sources.json`、内容・表示先は `src/data/privateMedia.ts` に記録しています。写真・料金・メニューは掲載時の資料であり、訪問時は各公式案内を確認してください。
