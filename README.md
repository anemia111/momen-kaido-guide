# 木綿街道、静かな一日。

町家の写真、老舗の手仕事、地元の料理を眺めながら、松江発の日帰り旅を計画するデジタルパンフレットです。

公開先：[木綿街道、静かな一日。](https://anemia111.github.io/momen-kaido-guide/)

## 写真から旅を選ぶ

- 深緑とアイボリー、大きな町家の写真、ゆったりした余白を使ったデザイン。
- 814・棉の花・喜多縁の料理と店内、老舗の商品・店構え・手仕事、本石橋邸の庭と座敷、ゆらりの露天風呂。
- 写真の切り替えと拡大表示。店名・キーワード検索、種類による絞り込み。
- 風風ラーメン平田店の公式メニュー全5ページ（2025年7月掲載）。
- 公式散策マップの表裏、両駅の公式時刻表、平日／土日祝の旅程、電話・予約・地図へのボタン。
- 各写真の掲載元リンク。814の夕食紹介写真はその旨を記載。加藤醤油店は確認済み写真がないため案内カードを表示。

## 開発と確認

`npm ci` → `npm run lint` → `npm run format:check` → `npm run build` → `npm test`

375・390・393・430pxのWebKit、768・1440pxのChromiumで、写真操作、検索、旅程、時刻表、地図、共有、タップ領域、アクセシビリティを確認します。mainへの更新はGitHub Actionsで検証し、GitHub Pagesに公開します。

写真の掲載元は `public/brochure-photos/sources.json`、内容・表示先は `src/data/privateMedia.ts` に記録しています。写真・料金・メニューは掲載時の資料であり、訪問時は各公式案内を確認してください。
