各幅4シナリオ、計24件すべて成功。旅程の平日／土日祝切替と正確な列車時刻、帰りの公式PDF、ランチ満席時の代替3店、公式Instagram・telリンク、手仕事の施設を混同しない絞り込み、全施設の地図ピンとApple Maps、横はみ出しの有無、44pxの操作領域、実行時エラーの有無、地図を開いた後も含むWCAG A／AAの自動検査、外部リンクの新規タブ・noopener、内部アンカー、Manifest／アイコン／OGPファイル、Web Share APIの呼び出し・キャンセル、クリップボードと権限拒否時の代替表示を検証しました。

`npm run lint`、`npm run build`も成功、TypeScriptエラーゼロ。GitHub Actionsでも同じ検証を実行します。WebKitはSafariと共通するブラウザーエンジンでの検証です。実物のiPhone、電話発信、実際の予約送信、現地徒歩、共有先アプリの操作は実施していません。共有APIのテストはブラウザー側のAPIを代替して呼び出しを検査しています。

地図・公式SNS・予約は外部サービスに依存します。リンク検査結果は[全件一覧](external-links.md)へ保存しています。HTTP200でもログイン画面や予約不可、臨時休業はあり得るため、当日確認を促す設計です。

最初の検証で発見した文字とボタン背景のコントラスト、スポット絞り込みの「駅」ボタンの横幅を修正してから再検証しています。不要なViteテンプレートの画像・設定は公開物から除外。地図コード約46KB gzipは初期表示から分割し、押すまでロードしません。初期JavaScriptは約86KB gzip、サイトCSSは約6.5KB gzip。外部のWebフォントや写真ダウンロードはありません。
